# Framer's AI Agent or an import plugin for your blog?

Framer's Agent can now move content into Framer: its Agents page says it "recreates pages, structure, and CMS content in Framer from a live site, export, or reference", and one of Framer's own sample prompts is moving WordPress blog posts into a CMS collection. We make Blog Import, an import plugin, so we have a stake in this; here is what Framer's own pages say and where each one fits. All quotes are from framer.com, read on 28 October 2026.

[Blog Import on the Framer Marketplace](https://www.framer.com/marketplace/plugins/blog-import-squarespace-wordpress/) is the plugin this page refers to; your newest 25 posts import free.

## What Framer says about the Agent

- Framer's migration guide (27 October 2026) ends with "Treat the Agent's result as a first build pass, not a finished migration", and asks you to "review dates, options, references, images, and formatted text after import."
- Redirects: the Agent can set them up from a spreadsheet of old and new addresses that you supply, on a plan that includes redirects.
- Cost: AI credits from your plan (Basic includes 1,000 a month, Pro 3,000). Framer doesn't publish how many credits a migration uses.
- Framer Experts moving client sites can get 50K credits per approved site through Framer's Switch program, and Framer's Switch page quotes a customer who moved "~500 CMS items" from a WordPress address.

## Where an import plugin is different

- Every post in the export is handled the same way, each time you run it, and running it again updates posts rather than duplicating them.
- Images inside the posts are copied into Framer, so they keep working after the old site is cancelled.
- The old addresses are read from the export itself, and on Framer Pro a redirect is added for each post; you don't build the spreadsheet.
- It reads export files, so it works from Squarespace, Blogger, Medium and Ghost exports, not only a live site.
- No AI credits. [Blog Import](/blog-import/) imports your newest 25 posts free; a license for the rest is $29 for one project or $59 for any number.

## Which to use

**A handful of posts, on a site you're redesigning anyway:** the Agent is likely enough, and you'll be checking each page by hand regardless.

**A whole blog with years of posts and images, or old links you need to keep:** an import plugin is the more predictable route. You can still use the Agent for the pages and the plugin for the blog.

**A live WordPress site that stays online and has custom post types:** a WordPress sync plugin may suit you better; [the comparison](/guides/framer-blog-import-plugins-compared/) lists them.
