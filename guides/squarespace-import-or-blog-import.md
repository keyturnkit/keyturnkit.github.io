# Squarespace Import or Blog Import

Two Framer plugins are built for moving a Squarespace blog into Framer CMS: Squarespace Import by Adam Kansky and Blog Import, which we make. So read this knowing we have a stake. The Squarespace Import details come from its Marketplace listing, read on 28 October 2026.

## What both do

Both read the file Squarespace exports in WordPress format (Settings, Advanced, Import & Export). Both bring each post with its title, date, body, excerpt and cover, keep drafts as drafts, make authors, categories and tags their own linked collections, copy the images inside posts into Framer so nothing breaks when you cancel Squarespace, carry YouTube and Vimeo over, and add a redirect from each dated Squarespace address (/blog/2024/3/9/my-post) to the new one on a Framer plan that includes redirects. Running either again updates the same collections instead of duplicating them. Squarespace Import imports the first 25 posts free; Blog Import is free with no limit on posts.

## Where they differ

| | Squarespace Import | Blog Import |
|---|---|---|
| Price | First 25 posts free, then $49 one project or $99 unlimited | Free |
| Other sources | Webflow, in a separate plugin (the $99 key covers both) | WordPress, Blogger, Medium, Ghost, Substack, Hashnode and Webflow in the same plugin |
| Framer Basic (2 collections) | Not mentioned on the listing | Option to keep authors, categories and tags inside each post |
| Try without an export | "See it on a sample" shows the review on a made-up blog | Needs an export file |
| Support | Email, replies within a day | Email |

## Which to pick

**You only have a Squarespace blog and want the sample preview.** Squarespace Import's sample lets you see the review screen before you export anything, and its listing is detailed about Squarespace's captions and lazy-loaded images.

**You care about price, or you are on Framer Basic.** Blog Import is free, and it has a layout for Basic's collection limit.

**You have more than one blog, or a client on WordPress, Blogger, Medium, Ghost, Substack or Webflow next.** Blog Import reads all of them in the same plugin. If your other site is on Webflow, Squarespace Import's maker has a Webflow plugin under the same unlimited key.

Either way, run both on your own export and compare the result before paying for Squarespace Import.
