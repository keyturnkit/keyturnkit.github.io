# Squarespace Import or Blog Import

Two Framer plugins are built for moving a Squarespace blog into Framer CMS: Squarespace Import by Adam Kansky and Blog Import, which we make. So read this knowing we have a stake. The Squarespace Import details come from its Marketplace listing, read on 28 October 2026.

## What both do

Both read the file Squarespace exports in WordPress format (Settings, Advanced, Import & Export). Both bring each post with its title, date, body, excerpt and cover, keep drafts as drafts, make authors, categories and tags their own linked collections, copy the images inside posts into Framer so nothing breaks when you cancel Squarespace, carry YouTube and Vimeo over, and add a redirect from each dated Squarespace address (/blog/2024/3/9/my-post) to the new one on a Framer plan that includes redirects. Running either again updates the same collections instead of duplicating them. Both import the first 25 posts free.

## Where they differ

| | Squarespace Import | Blog Import |
|---|---|---|
| License after 25 posts | $49 one project, $99 unlimited | $29 one project, $59 any number |
| Other sources | Webflow, in a separate plugin (the $99 key covers both) | WordPress (file or live site), Blogger, Medium, Ghost, Substack, Hashnode and Webflow in the same plugin |
| Framer Basic (2 collections) | Not mentioned on the listing | Option to keep authors, categories and tags inside each post |
| Try without an export | "See it on a sample" shows the review on a made-up blog | Needs a file, or a live WordPress address |
| Support | Email, replies within a day | Email |

## Which to pick

**You only have a Squarespace blog and want the sample preview.** Squarespace Import's sample lets you see the review screen before you export anything, and its listing is detailed about Squarespace's captions and lazy-loaded images.

**You care about price, or you are on Framer Basic.** Blog Import is $20 less for one project and $40 less unlimited, and it has a layout for Basic's collection limit.

**You have more than one blog, or a client on WordPress, Blogger, Medium, Ghost, Substack or Webflow next.** Blog Import reads all of them with one license. If your other site is on Webflow, Squarespace Import's maker has a Webflow plugin under the same unlimited key.

Either way, import your 25 newest posts free in both and compare the result on your own blog before paying.
