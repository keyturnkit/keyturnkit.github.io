# Thanks for your purchase

Bought on Gumroad? Your key is in the Gumroad receipt email; skip to the steps below.

Polar sends a confirmation email with an **Access purchase** button. That button opens your purchase on Polar, where the key or the download is. If the email hasn't arrived, open [the Mam Studio customer portal](https://polar.sh/mam-studio/portal) and sign in with the email you paid with.

## Blog Import license

1. Copy the license key from your purchase. On Polar it starts with `BLOGIMPORT-`. On Gumroad it is in the receipt email and on the purchase page, four groups of eight letters and numbers.
2. Paste it on the [license code page](https://blog-import-license.mam-studio.workers.dev/code) and press **Get code**.
3. In Framer, run Blog Import, paste the code into the **License code** box and press **Activate**.

The plugin checks the code itself and sends nothing anywhere. Keep the code: you can paste it again in the same project after reinstalling. Each new code uses one activation of your key, and the $29 license has 3.

## Keyturn Kit Pro

Download the zip from your purchase on Polar, unzip it and follow `README.md`. `AGENTS.md` in the same folder tells Claude Code or Cursor how the license code is laid out.
