What happens after someone pays

Lemon Squeezy, Polar and Dodo are merchants of record: they take the payment and handle sales tax. The extension only ever talks to their license API.

  1. At checkout

    Upgrade opens your provider's hosted checkout page. You never see a card number.

  2. A minute later

    The provider emails the buyer a license key.

  3. When they paste it

    The extension checks the key belongs to your store, then activates it, which uses one of the activations you allow per key.

  4. Every 24 hours

    The key is checked again. A key you disable stops working at the next check.

  5. Without internet

    Pro keeps working for 7 days after the last good check, so a train ride doesn't lock anyone out.

  6. After a refund

    Disable the key in your provider's dashboard, and Pro locks at the next daily check.

Keys from other stores are rejected by store, organization or business id. Without that check, a key bought from any seller on the same provider would turn your Pro features on.

One file to edit

Put in your store id and checkout link, wrap the paid part of your extension in <ProGate>, and build. Switching providers in Pro changes one line.

This is the free edition's config as it is on GitHub.

lib/config.ts

// The only file you need to edit to sell your extension.

export const config = {
  provider: 'lemonsqueezy' as const,

  /** Where the Upgrade button sends people. */
  checkoutUrl: 'https://YOUR-STORE.lemonsqueezy.com/buy/YOUR-VARIANT-ID',

  lemonsqueezy: {
    /** Settings > Stores in the Lemon Squeezy dashboard. */
    storeId: 0,
    /** Leave empty to accept any product in your store. */
    productIds: [] as number[],
  },

  /** How often to re-check the key with Lemon Squeezy. */
  recheckHours: 24,
  /** How long Pro keeps working when the license server can't be reached. */
  offlineGraceDays: 7,
};

Questions

Can someone crack it?

Yes. Anything checked inside an extension can be patched by a determined person. What the kit stops is a key being shared past the activation limit you set, and a key you've disabled continuing to work. If you need more than that, put the valuable part on a server and gate that.

Does it work in Firefox?

WXT builds a Firefox version with npm run zip:firefox. We have tested Chrome only so far, so treat Firefox as untested.

Why not ExtensionPay?

ExtensionPay is a good hosted service built on Stripe, with its own login and a 5% fee on top of Stripe's. Keyturn Kit is code you own, with no extra fee, and it works with merchant-of-record providers that handle sales tax for you. If you'd rather not touch code, ExtensionPay is the easier choice.

Do I need a backend?

No. Lemon Squeezy, Polar and Dodo all have license endpoints that are meant to be called from client apps without a secret. Creem isn't supported because its license API needs a secret key.

What happens when I refund someone?

Disable their key in your provider's dashboard. The extension locks Pro at its next daily check. We don't promise that a refund disables the key on its own, because not every provider documents that.
