License keys for paid Chrome extensions

Keyturn Kit is a WXT + React starter for selling a Chrome extension. The buyer pays on Lemon Squeezy (or Polar or Dodo in Pro), gets a license key by email and pastes it into your extension. The extension checks the key with the provider's public license API. You don't run a server and no secret key ships in the extension.

Free edition on GitHub 
git clone https://github.com/keyturnkit/keyturn-kit
cd keyturn-kit
npm install
npm run dev     # opens Chrome with the extension loaded

This is the popup the free edition ships with, built from the repo and running in this page. Paste KEYTURN-DEMO-2026 and press Activate to see Pro turn on, or any other key to see the error your users would get.

In this page only, the calls to Chrome storage and to Lemon Squeezy are answered by a small script. In your extension they go to the real APIs.

Gating a feature

<ProGate>
  <BulkExport />
</ProGate>

if (await license.isPro()) { ... }

Set your store id and checkout link in lib/config.ts. The free edition then:

  • rejects keys from other Lemon Squeezy stores, so a key bought from someone else's product can't turn on yours;
  • re-checks the key every 24 hours, so a key you disable after a refund stops working the next day;
  • keeps Pro working for 7 days without a connection;
  • has 15 tests with the network mocked.

Questions

Can someone crack it?

Yes. Anything checked inside an extension can be patched by a determined person. The kit stops a key being shared past the activation limit you set, and a disabled key from carrying on. If you need more, put the valuable part on a server and gate that.

Why not ExtensionPay?

ExtensionPay is a hosted service on Stripe with its own login and a 5% fee on top of Stripe's, and you handle sales tax yourself. Keyturn Kit is code you own with no extra fee, and Lemon Squeezy, Polar and Dodo collect and pay the tax. If you'd rather not touch code, ExtensionPay is easier. There's a longer comparison.

Firefox?

WXT builds it with npm run zip:firefox. We have only tested Chrome.
