# Blog moved into Framer for you

If you'd rather not run the import yourself, we do it in your Framer project with [Blog Import](/blog-import/) and check the result post by post. $149 per blog, paid once.

[Buy the move, $149](https://buy.polar.sh/polar_cl_OybrcvOw3RlPUmfT3UkDy3BO14Lfpx6KIw9Xq3aERLv)

## What you send

- The export file from your old blog, or its address if it's a WordPress site that's still online. Squarespace, WordPress, Blogger, Medium and Ghost are all fine. The [export inspector](/tools/blog-export-inspector/) shows what's in the file before you send it.
- An invite to your Framer project. After you pay we reply with the address to invite, as an editor.

## What we do

- Import every post into Framer CMS, with authors, categories and tags. The Blog Import license for that project is included.
- Copy the images into Framer, so they keep working after you cancel the old site.
- Add a redirect from each old post address to the new one. Framer only offers redirects on its Pro plan and higher, so on Basic we send you the list to add if you upgrade.
- Open the posts and check for missing images, broken embeds and empty bodies, then send you a short report of anything that didn't come across and why.
- Leave your project when we're done.

We don't design pages or touch anything else in the project. If your site doesn't have a blog page yet, Framer's collection page does the job until you style one.

## How long it takes

Usually within two days of getting the file and the invite. Large blogs with thousands of images can take longer, and we tell you if that's the case before we start.

## If it can't be done

If something in your export means we can't move the blog, you get a full refund.
